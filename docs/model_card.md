# SearchForge · Model Card（旗舰 RankFuse）

作者：晨星 (CJX0712) · v0.1.0 · 2026-10-07

---

## 模型概况

| 字段 | 值 |
|------|-----|
| 名称 | RankFuse（SearchForge 旗舰重排器） |
| 类型 | 两段式检索 + 学习重排（LambdaMART / LightGBM） |
| 用途 | 给定查询与文档集合，输出按相关性排序的文档列表 |
| 输入 | 查询词序列 + 文档集合 |
| 输出 | doc_id 排序列表 |
| 训练数据 | 系统内合成语料（确定性 DGP），**不含任何真实用户数据** |
| 语言 | 与语言无关（合成词表为抽象 token id） |
| 许可证 | MIT |

---

## 架构与决策

1. **第一阶（召回）**：BM25（词法）+ FAISS over LSI（语义）双路各召回 top-K；
2. **融合**：Reciprocal Rank Fusion（k=60），免训练、对 k 不敏感（实测 k∈[10,200] 波动 <0.003）；
3. **第二阶（重排）**：LightGBM LambdaMART，对 top-N=60 候选重排，剩余保持初排顺序。

**为什么用 LambdaMART**：listwise/pairwise 的排序目标直接优化 nDCG，
比 pointwise 回归更贴合检索指标；LightGBM 实现成熟、CPU 高效、可确定性复现。

## 特征（6 维）

| 特征 | 含义 | 来源 |
|------|------|------|
| `bm25` | BM25 词法得分 | rank_bm25（缺则 TF-IDF 余弦） |
| `dense` | 稠密语义相似度（余弦） | LSI + FAISS（缺则 numpy 精确余弦） |
| `rrf` | RRF 融合排名倒数 1/(k+rank) | 两路召回排名 |
| `overlap` | 查询-文档共享词数（带重数） | 词频统计 |
| `doc_len` | log(1+文档长度) | 文档 |
| `query_idf` | 查询词 idf 之和（查询特异性代理） | 语料统计 |

**特征不含标签代理**：标签（分级相关性）依赖**潜在主题**这一隐变量，
任何单个特征都无法单独决定它。这一点经过专门设计与回归验证——
早期把相关性定义为"共享词数 ≥ 阈值"时，`overlap` 特征几乎等同于标签，
产生了 +10~13% 的**伪增益**；修正定义后增益回落到可核查的真实值。

## 训练与评测协议

- 查询按 6:4 划分为 train / test，重排器**只在 train 查询上拟合**
- 评测在 held-out test 查询上进行（单测断言两集合不相交）
- 语料（被检索的文档集合）共享——符合真实检索设定；TF-IDF/LSI 只在语料上拟合
- 多 seed（≥3）报 mean ± std；胜基线判据 = 均值差 > ½(σ₁+σ₂)
- 超参在**独立验证种子（9042）**上调优，与基准种子不相交

## 实测性能

| 指标 | 旗舰 | 最强基线（BM25） | 相对 |
|------|------|-----------------|------|
| nDCG@10 | 0.9086 ± 0.0175 | 0.8132 | **+11.73%** |
| nDCG@5 | 0.9080 ± 0.0205 | 0.8187 | +10.91% |

随机对照 nDCG@10 = 0.0246（证明任务非平凡）。全部数字来自 `benchmark.json`。

## 限制与风险

1. **不扩大召回**：只重排候选窗，Recall@100 受第一阶约束（已知限制）。
2. **合成数据**：结论在合成语料上建立；迁移到真实集合需重新体检难度与标定。
3. **极难查询可能劣于初排**：实测存在（失败案例 q=266）。
4. **语义表示容量有限**：LSI 是线性方法，难以刻画复杂语义；
   真实部署应替换为稠密神经编码器（本环境不允许下载外部权重）。
5. **不适用**：本模型为检索排序组件，**不做**内容生成、事实性判断或安全过滤。

---

## 公平性与伦理

训练数据为程序生成的合成语料，不含真实个人信息、不含人类标注者的主观偏见，
因此不存在来自标注者的人口统计偏差。但因未使用真实数据，
模型在真实语料上的行为（尤其是词表分布差异带来的偏差）**未经评估**，
部署前须在目标语料上重新评测。
